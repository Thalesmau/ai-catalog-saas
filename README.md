# Catalog AI

Mini SaaS multi-tenant onde empresas cadastram produtos e um agente de IA responde perguntas consultando dados reais do banco.

> 🚧 Em desenvolvimento.

## Stack
- **Backend:** Node.js, TypeScript, Express, MongoDB, Anthropic SDK (tool calling + SSE)
- **Frontend:** React, TypeScript, Vite, Tailwind, shadcn/ui
